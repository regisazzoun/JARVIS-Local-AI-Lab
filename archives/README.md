# Archives récupérées

Les rapports Markdown et scripts documentaires retenus sont conservés avec leur nom et contenu dans [recuperation-2026-10-14](recuperation-2026-10-14/). Les autres preuves textuelles sûres sont regroupées dans les TAR.GZ de [preuves-controlees](preuves-controlees/), sans exécution. Les chemins internes préservent la provenance. Chaque fichier possède une empreinte SHA-256 et une destination précise dans le [manifeste](../indexes/MANIFESTE.json). Les originaux sensibles et binaires restent locaux.

Les [empreintes des paquets](../indexes/PAQUETS.json) permettent de vérifier les téléchargements. Ne pas lancer les scripts historiques sans une mission distincte.
