# Accès JL-03

Application installée sur le Mac mini Debian : **http://localhost:8766/** après tunnelSSH8766. Prototype : http://localhost:8766/prototype.html. Depuis le MacBook, télécharger la branche de réalisation du [dépôtJL-03](https://github.com/regisazzoun/JARVIS-Launcher3/tree/codex/mission-27-jl03), puis ouvrir macos/Ouvrir-JL03.command ; le profilJL-02local est lu sans être remplacé. Garder cette fenêtre ouverte. Connexion web existante réutilisée surlocalhost, sinon une identification JARVIS.

Les tunnelsLiveKit7880/7881 restent nécessaires au modeprototypeoptionnel, sans changement deJL-02. L'absence de configurationSSHlocale ne peut pas être corrigée depuisDebian sans accèsauMac ; profil/clé existants réutilisés, aucune installation nativeMacprétendue.
