# Rectification du rendu factuel générique

Le fichier DEMO-FACTS.md conserve tel quel le rendu déterministe déclenché parCodex. Sa phrase générique sur un événement model_report_original ne correspond pas à cette démonstration non autonome (spec.autonomous=false). Ici l'original est conservé dans les arguments du vrai intervention_report et dans DEMO-JARVIS-ORIGINAL.md, pas dans un événement de ce nom. Les états, références et contrôles listés restent issus du journal. Cette réserve du texte générique est identifiée sans modifier sa sortie originale.
