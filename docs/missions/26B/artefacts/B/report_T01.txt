### Fichier producer.py
Lecture effectuée (invocation_id: `ec4f3297dd3d42a9a3a3da1c2cd7554c`, evidence_id: `b776288ad3b947c8a362825e862df451`).

Le script utilise :
- argparse pour la ligne de commande avec arguments source, destination et --delimiter (défaut=',')
- csv.DictReader pour lire le fichier CSV avec le délimiteur spécifié
- Écrit un JSON avec `count` (nombre de lignes) et `sum` (somme des valeurs entières de la colonne 'valeur')

Code observé :
```python
import argparse,csv,json
from pathlib import Path
p=argparse.ArgumentParser();p.add_argument('source');p.add_argument('destination');p.add_argument('--delimiter',default=',');a=p.parse_args()
with open(a.source,newline='') as f: rows=list(csv.DictReader(f,delimiter=a.delimiter))
result={'count':len(rows),'sum':sum(int(r['valeur']) for r in rows)}
Path(a.destination).write_text(json.dumps(result,sort_keys=True)+'\n')
print(json.dumps({'produced':a.destination,'result':result}))
```
